
# PROJET IA – ENSEIGNEMENT SCIENTIFIQUE
## Guide de l'élève

**Développer une application de physique avec Mistral Vibe**

Ce guide explique comment rejoindre son groupe, créer
une application avec une intelligence artificielle et
enregistrer automatiquement les versions du projet.

---

## 1. Objectif du projet

Vous allez travailler en groupe pour développer une
application interactive de simulation de physique.

Vous utiliserez :
- Mistral Vibe pour développer l'application.
- GitHub pour conserver les fichiers et leurs versions.

Vous n'avez pas besoin de savoir programmer.

Chaque groupe comporte au maximum 3 élèves.

## 2. Créer son compte GitHub

Cette opération n'est nécessaire qu'une seule fois
si vous ne possédez pas déjà de compte.

1. Ouvrir https://github.com/signup
2. Créer un compte personnel.
3. Choisir un identifiant GitHub.
4. Confirmer son adresse électronique.
5. Conserver ses identifiants de connexion.

Ne communiquez jamais votre mot de passe.

## 3. Créer son compte Mistral

1. Ouvrir https://chat.mistral.ai/
2. Créer un compte personnel si nécessaire.
3. Vérifier que Mistral Vibe est accessible.

Utiliser uniquement les fonctionnalités gratuites
autorisées dans le cadre du projet.

Ne souscrivez aucun abonnement payant.

## 4. Rejoindre son groupe GitHub

Portail permanent :

https://enseignement-scientifique.github.io/inscription-eleves/

Cette fonction sera activée lorsque le professeur
annoncera l'ouverture des inscriptions.

Lors de la première inscription :

1. Ouvrir le portail.
2. Se connecter avec son compte GitHub.
3. Choisir son groupe.
4. Saisir le code secret fourni par le professeur.
5. Valider l'inscription.
6. Accepter l'invitation GitHub reçue.

Le code est propre à chaque groupe.

Ne communiquez pas votre code à des élèves
extérieurs au groupe.

L'inscription n'est nécessaire qu'une seule fois
par année scolaire.

## 5. Ouvrir le projet dans Mistral Vibe

1. Se connecter à Mistral.
2. Ouvrir Mistral Vibe.
3. Accéder à la fonction d'utilisation de GitHub.
4. Autoriser l'accès au dépôt du groupe si demandé.
5. Sélectionner le dépôt GitHub attribué au groupe.

Le nom du dépôt sera communiqué par le professeur.

Tous les membres du groupe travaillent sur
le même dépôt GitHub.

## 6. Développer l'application

Décrire précisément à Mistral Vibe
l'application de physique souhaitée.

Exemple de demande :

"Crée une application HTML autonome permettant
de simuler la chute libre d'une bille.

Je souhaite pouvoir modifier la hauteur initiale,
lancer la simulation, visualiser le mouvement
et afficher les graphiques de position et
de vitesse en fonction du temps."

Examiner le résultat et demander des corrections.

Effectuer plusieurs améliorations successives.

## 7. Enregistrer les modifications

Mistral Vibe est chargé de transmettre les
modifications au dépôt GitHub du groupe.

Les élèves ne doivent pas déposer manuellement
leurs fichiers dans GitHub.

Après une modification importante, vérifier
qu'elle a bien été enregistrée dans GitHub.

Chaque enregistrement doit permettre de suivre
l'évolution du projet.

Les sauvegardes complémentaires sont gérées
automatiquement par le système du professeur.

## 8. Tester l'application

Ouvrir l'application produite et vérifier :

- Le fonctionnement des commandes.
- La cohérence des résultats physiques.
- La qualité des graphiques et animations.
- L'absence d'erreurs visibles.
- La clarté de l'interface.

Pour une application HTML autonome, le fichier
principal sera normalement index.html.

Si plusieurs fichiers sont nécessaires,
ils doivent tous être conservés dans le dépôt.

## 9. Lors des séances suivantes

1. Se connecter à Mistral Vibe.
2. Retrouver le projet de son groupe.
3. Continuer le développement.
4. Vérifier l'enregistrement des modifications.

Il n'est pas nécessaire de refaire l'inscription
au groupe à chaque séance.

Une nouvelle connexion à GitHub ou Mistral
peut toutefois être demandée si la session expire.

## 10. Travail final

À la date indiquée par le professeur :

1. Vérifier que l'application fonctionne.
2. Vérifier que les derniers fichiers sont
   enregistrés dans le dépôt GitHub du groupe.
3. Vérifier que les versions successives
   sont consultables.
4. Communiquer au professeur que le projet
   est terminé, selon ses consignes.

Ne supprimez pas le dépôt GitHub du groupe.

## 11. Fin de l'année scolaire

Le système prévoit une remise à zéro annuelle
le 1er septembre.

Les inscriptions, les groupes et les travaux
de l'année précédente seront supprimés,
y compris les sauvegardes correspondantes.

Conservez une copie personnelle de votre travail
avant cette date si vous souhaitez le garder.

## 12. Règles importantes

- Utiliser Mistral Vibe pour le développement.
- Ne pas utiliser un abonnement payant.
- Ne pas partager ses mots de passe.
- Ne pas publier de données personnelles.
- Ne pas modifier les travaux d'un autre groupe.
- Respecter les consignes du professeur.
